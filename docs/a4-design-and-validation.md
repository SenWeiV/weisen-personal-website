## 实现

- `assembly.js` 取代 A3 的 `field.js`：144 个实体分面单元、线框、12 条轨道、108 个信号点，由数学函数实时生成。使用深度测试；全页共享一个 WebGL 画布。
- 编织骨架、模块阵列、精密网格、放射结构按内容连续重组；实验区提供 0 / 55 / 100 三个预设，默认与复位为 Structure / 55%。
- 自动旋转与起伏幅度增大；拖动灵敏度与释放惯性增强；按住会临时展开，点击 / Space / Send pulse 会触发传播波动，指针附近有局部反馈。
- Unfold / Assemble 在首屏和实验区共享状态，使用质量 1、刚度 100、阻尼 10 的弹簧。暂停时直接到目标状态，保留键盘与静态操作。
- 全页底色为首页的 `#e8e9e4`。文字为 `#272e31`；电光蓝 `#2855ff` 用于少量实体、轨道信号、当前状态及当前工作。实验区与页脚不再换成深底。
- Garena 经历按用户提供的原文加入：`2026 — present / Agent Harness & Data evaluation`。Baidu 收束为 `2025 — 2026`。页头、首屏及自我介绍同步当前工作；历史项目继续归属 Baidu。
- 保留十个项目资料、原生 dialog / details、系统减少动态效果、全局暂停、页面隐藏时停止渲染，以及简化 Canvas 2D 回退。

## 验证记录

本地浏览器已确认 WebGL 正常编译并显示实体、轨道和蓝色信号。开发时发现并修复了一处着色器阶段的精度不一致；修复后使用 WebGL，未把 Canvas 回退当作 WebGL 成功。

桌面检查包括展开状态同步、参数和键盘调整、项目面板打开与 Esc 关闭、焦点返回，以及全页实际背景色。主要章节的透明背景继承 body，其余章节的实际背景为同一 `rgb(232,233,228)`。

静态检查没有重复 ID、缺失的页面锚点或本地资源；图片及视频元素为 0。JavaScript 语法检查通过。

- 1440 × 900、1280 × 720 桌面，以及 390 与 320 像素手机宽度没有横向溢出；390 宽度下图形与全部控制器可同时操作。手机渲染分支在重新加载后实测，使用较低像素密度上限及较少轨道分段。1280 × 720 下说明与控制器之间实测有 37 像素间距，没有重叠。
- 鼠标拖动、方向键和 Space 均已操作；Unfold / Assemble 两处按钮共享选中状态。滑杆的 Home / End 和三个预设可改变数值；Reset view 回到 55%。
- 修复了画布位置和尺寸插值落后于 DOM 的问题。现在操作区域、图形中心和尺寸直接同步；仅内部模块形态连续重组。展开和按住时同步调整观察尺度，避免结构无限膨胀。
- 手动暂停禁用脉冲。稳定后隔开的两张暂停截图字节完全相同；暂停后仍能直接展开。刚点击暂停时的首次截图可能包含最后一帧，不用该过渡帧判定持续运动。
- 系统 reduced-motion 以浏览器模拟后重新加载验证：暂停按钮标注系统减少动态效果并禁用，脉冲禁用，静态展开可用。本轮没有验证真实操作系统偏好在不重载时的动态切换。
- 禁用脚本重新加载后，十个项目记录与五个内联代码 SVG 仍在，动态控制器隐藏，媒体元素为 0。测试后已恢复脚本和系统偏好模拟。

当前 HTML、CSS、assembly.js 和 main.js 的本地 HTTP 请求均返回 200；终版加载未出现新的 error / warn。

本轮未做真实手机硬件、Safari、帧率基准和 WebGL 上下文丢失的实机测试。没有据源码存在回退就声称旧设备已经验证。
