Medical agent evaluationEvaluation+

Medical agent evaluation pipeline

Five decoupled stages, wiki, generation, refine, eval and analyse, for a Plan-Act medical consultation agent. Wiki-RAG writes case-specific rubrics and Propose-Evaluate-Revise sharpens them.

医疗问诊 Agent 五阶段解耦评测 Pipeline，覆盖 50+ 临床病种，Cohen’s κ = 0.78。

Virtual persona evaluationEvaluation+

Virtual persona agent evaluation

Specification-driven scoring for companion agents in WenXiaoYan, Shoubai and in-car products: -1/0/1 over an 11-dimension analytic rubric.

-1/0/1 Likert 评分 + 11 维 Analytic Rubric，21+ 批次黑盒批跑，标签一致率 97%。

21+ batch runs, 97% label consistency, reused across 3 products.

Micro-expression evaluation suite
